# おれんじさん🍊 ロゴ

訪問看護予約システム「おれんじさん」のロゴアセットです。

## コンセプト

- **オレンジの実**:サービス名「おれんじさん」の由来。温かく親しみやすい印象
- **ハート**:患者さんに寄り添うケアの心
- **クロス**:看護・医療のシンボル
- **葉と枝**:健やかさ・自然体の暮らし

## ファイル一覧

| ファイル | 用途 |
|---------|------|
| `logo-mark.svg` | ロゴマーク単体(アプリアイコン、ファビコン、LINEリッチメニューなど) |
| `logo-horizontal.svg` | 横組みロゴ(ヘッダー、ドキュメント、資料の表紙など) |
| `logo-mark-mono.svg` | 単色版(スタンプ、FAX、1色印刷など。`fill` の色は変更可) |

## ブランドカラー

| 色 | HEX | 用途 |
|----|-----|------|
| オレンジ(メイン) | `#F07818` | ボタン、アクセント、クロス |
| オレンジ(ライト) | `#FFB65C` | グラデーション上部、背景 |
| リーフグリーン | `#5FA33C` / `#8CC152` | 葉、サブアクセント |
| ブラウン | `#5C4632` | ロゴタイプ、見出し文字 |

## 使用上の注意

- ロゴの縦横比は変えないでください
- 余白はマークの高さの1/4以上を確保してください
- 濃い背景に置く場合は単色版を白(`#FFFFFF`)にして使用してください
